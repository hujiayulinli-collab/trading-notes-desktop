# 盘口手记：Windows 本地桌面版

本目录是在原版基础上添加的桌面外壳，不是交易看板或 Telegram Bot。原有网页开发/构建命令仍保留。桌面版使用 Electron 复用 React 页面与现有本地文件服务，避免重写交易计算、备份导入、截图校验和周报逻辑。

## 安装与开发

开发者在 Windows x64 安装官方 Node.js 22.18+（建议当前 LTS）及 pnpm 11，然后双击 `桌面版构建.cmd`，或运行：

```
pnpm install --frozen-lockfile
pnpm desktop:win
```

NSIS 安装包在 `release/`。开发启动：`pnpm desktop:start`。安装后的用户不需要 Node.js 或 pnpm。安装包不需要管理员权限；默认当前 Windows 用户安装，支持更改安装位置。未配置代码签名，不要承诺消除 Windows SmartScreen 提示；对外发布应由维护者签名。

## 第一次使用

首次打开选择一个空文件夹，或包含 `journal.json` 的现有本地资料库。不会导入你未选择的旧目录，也不使用浏览器存放交易。旧版数据迁移前先复制整个旧文件夹备份。

- 交易：所选目录的 `journal.json`、`journal.previous.json`
- 原始截图：`screenshots/`
- 周报：`weekly-reviews/generated/`（在同一个所选目录中）
- 本机保存位置、应用锁配置：Windows 用户的应用数据目录，不写入安装目录
- 更改保存位置：设置 → 选择文件夹 → 迁移资料库；目标必须为空，复制校验成功才切换，旧目录保留

旧网页服务的周报可能位于旧项目根目录的 `weekly-reviews/generated/`，与旧 `data/` 分开。迁移前退出两边程序，另行完整备份这一目录；不要只复制 `data/`。内置 JSON 备份包含交易及截图，但不包含独立周报，完整迁移和保护周报必须复制整个新资料文件夹。

选择 OneDrive、Dropbox 或其他同步文件夹，可能触发对应软件的自动上传；若要完全留在本机，选择非同步本地目录。

## 可选本地应用锁（不是文件加密）

默认免密使用。设置中可添加本地应用密码、修改或关闭密码，并可点击“立即锁定”。设置/关闭已有密码需要旧密码。重启后需解锁；错误密码不会显示资料。锁定时本地 HTTP 服务也拒绝页面、截图和记录请求，不只是盖住画面。

**这只是防止别人随手打开应用。磁盘上的 JSON、截图、周报及导出备份仍是明文。** 能登录同一 Windows 用户、读取资料目录或修改程序/锁配置的人可以直接看文件或绕过应用锁。它不防管理员、恶意软件、内存取证，也不是加密保险箱。建议同时使用 Windows 锁屏、独立系统账户和系统磁盘加密。

密码采用带随机盐的 scrypt 验证值，本机不保存明文密码。没有网络账户、没有云端找回密码；忘记密码请联系维护者了解本机应用锁重置，原文件仍可由操作系统直接读取。不得宣传为加密恢复或安全账户认证。

## 网络与隐私边界

桌面模式固定绑定 `127.0.0.1` 的随机空闲端口；不打开局域网，不修改防火墙。每次启动生成独立随机会话令牌，不放在 URL 或网页脚本中。窗口启用 sandbox、contextIsolation、禁用 Node 集成，IPC 仅允许可信主框架调用受限功能。渲染器禁止外网请求、新窗口和外部页面导航；会话内存分区不保存浏览器资料。

桌面界面不提供原网页的 Supabase 云端入口，也不会自动读取或连接云配置。原网页模式的云功能源码保留。

GPT 复盘仍是主动功能：填写自己的 API Key 并发起分析时，现有本地服务会把界面所说明的选中资料发送给 OpenAI。API Key 只在本次界面内存使用；本次开发测试没有调用真实 OpenAI/Supabase，也没有发送交易或截图给站点所有者。

## 保留的功能与限制

交易/截图/计算、迁移、JSON 备份、周报准备与 API 分析继续复用原实现。安装外壳没有替代原网页服务的功能。原有 Codex 周报手工命令面向源代码工程，安装版没有独立系统 Node 或工程 CLI；不要直接执行周报文件里旧的工程相对路径。需要该手工流程时请使用本源代码项目，或在桌面内使用原有主动 GPT 分析功能。

锁定仅影响新请求；已开始的保存、导出或分析不会被粗暴中断。点击锁定按钮会先保存编辑并等待保存完成。退出不会在服务接受写入时直接强杀进程。

## 必须完成的 Windows 真机验收

以下是发布前清单，不代表这些步骤已在本次 Linux 环境中执行：

1. 全新安装、选择含中文路径的空文件夹、取消首次选择再启动
2. 新建/编辑交易、原图上传、重启后记录及截图存在
3. JSON 导出/导入、重复导入、原目录保留的迁移与移动磁盘断开报错
4. 已有资料库打开、另一个进程持锁时拒绝打开
5. 免密使用；设置密码、错误密码、重启解锁、修改/关闭密码、立即锁定
6. 锁定后原本 HTTP 地址和截图不能读取，解锁后正常
7. 周报准备、备份独立周报、下载报告、迁移后仍能读取报告
8. 连续点击文件夹选择只弹一个窗口，取消不修改目录
9. 安装更新/卸载不删除用户数据，双击第二次启动只激活原窗口
10. 普通用户账户安装启动，防火墙不增加规则，无云端登录/自动请求

本次自动化结果与实际限制见 `DESKTOP-VERIFICATION.md`。
