# 盘口手记：免费云端设置

接入功能已经准备好。你需要创建自己的 Supabase 项目并完成下面的一次性设置，才能真正登录云端。当前尚未连接真实项目。

## 1. 创建免费项目

打开 [Supabase 控制台](https://supabase.com/dashboard)，注册或登录，创建 **Free** 项目，例如命名为 `pankou-journal`。选择方便连接的地区，并保存数据库密码；这个密码不需要填入盘口手记，也不需要发给我。

截至 2026-09-06，免费计划包括每项目 500 MB 数据库、1 GB 图片等文件存储，以及 5 GB 非缓存流量与 5 GB 缓存流量。最多两个活跃免费项目，闲置一周可能暂停，不包含自动备份。截图通常比交易文字更快占用空间，仍建议定期导出完整备份。限制以 [Supabase 官方价格页](https://supabase.com/pricing) 为准。

## 2. 初始化资料库

在盘口手记页面打开 **设置 → 连接云端资料库 → 下载建库文件**。也可以直接打开本目录的 `setup.sql`。

在 Supabase 项目左侧打开 **SQL Editor**，新建查询，将建库文件的**全部内容**复制进去，点击 **Run**。成功后会有一张交易资料表、两个保存/读取接口和一个私有截图存储桶。这个文件可重复运行，不清空手记。

该文件为本应用独立设计，建议使用新项目。不要改成允许所有人读写的权限；公开连接密钥的访问范围由登录账号和数据库规则共同决定。[官方数据保护说明](https://supabase.com/docs/guides/database/secure-data)

已经用过旧版固定四模块的项目，也需重新运行最新版完整 `setup.sql`，才能保存新增或删除的模块。脚本会更新模块数量限制，保留现有手记和权限。执行后刷新手记页面；本地资料库无需这一步。

## 3. 创建你的手记账号

Supabase 的管理账号与手记里的登录账号是两回事，可以使用同一个邮箱。

进入 **Authentication → Users → Add user → Create new user**，输入你的邮箱和专门用于手记的密码，保持 **Auto confirm user?** 勾选，再点击 **Create user**。

个人使用建议随后在 Authentication 的用户注册设置中关闭 **Allow new users to sign up**。这不会阻止你刚创建的账号登录。[官方认证设置](https://supabase.com/docs/guides/auth/general-configuration)

后台创建并自动确认账号不需要注册邮件服务。Supabase 默认邮件服务只向项目组织成员的邮箱发送，并有每小时两封等限制；本应用使用后台创建账号后的邮箱密码登录。[官方邮件限制](https://supabase.com/docs/guides/auth/auth-smtp)

## 4. 在手记中填写公开连接信息

从项目的 **Connect** 面板复制 **Project URL** 和 **Publishable key**，也可以在 **Settings → API Keys** 找到密钥。[官方密钥说明](https://supabase.com/docs/guides/getting-started/api-keys)

- 项目地址形如 `https://你的项目编号.supabase.co`。
- 公开密钥以 `sb_publishable_` 开头，旧版 `anon` 公钥也支持。
- 不要填写数据库密码、`sb_secret_` 或 `service_role`；页面会拒绝这些私密凭据。

回到 **设置 → 连接云端资料库** 填入两项，点击继续，然后使用刚创建的手记账号登录。连接成功且交易保存完成后，页面顶部显示 **已保存到云端**。

## 5. 导入本地交易与在另一台设备使用

在连接云端前，先从本地资料库 **导出完整备份**。登录云端后，在设置中 **导入备份**，核对数量后确认。交易、原图、自定义条件和 GPT 复盘都会迁移。相同 ID 的交易会跳过；条件选项合并，不改写已有交易的条件文字。

另一台电脑运行同一个程序，填写相同的项目地址及公开密钥，登录同一个手记账号，即可访问同一份云端数据。无需复制整个资料文件夹。当前页面仍由本机程序打开；本次接入的是云存储，尚未发布供手机或浏览器直接访问的在线网址。

修改后约 650 毫秒自动保存。页面回到前台以及每 30 秒，会在没有未保存改动时检查云端更新。两台设备同时编辑时，后保存的旧版本会提示冲突；先下载未保存文字，再重新载入新版本，手动补回需要的修改。断网时未保存文字暂存当前页面内存，不能把它当作已存云端的离线副本。

## 备份、截图与 GPT

- 完整备份上限 200 MB，包含当前交易引用的原图和自定义条件，不包含密码、登录凭证或 GPT 密钥。
- 图片桶为私有。页面使用临时链接显示图片；不要将该链接分享给他人。
- 删除截图或交易先移除引用，原图文件暂时保留，避免其他设备尚未完成的保存造成图片丢失。它们仍占用云端空间，不会进入后续完整备份。清理存储前先导出备份。
- 云端文字快照上限 16 MB，每笔最多 8 张、每张最多 8 MB 的截图。图片独立存储，不占用文字快照限制。
- 页面内 GPT 复盘仍使用本机服务转发请求，密钥只保留在当前页面内存。云端截图会在你点击复盘后下载并送入该次请求。未来发布纯在线网址时，还需部署相应的 GPT 服务；复制资料到 ChatGPT 的方式始终可用。
- 登录过期或别处切换账号时，页面锁定并保留尚未保存的内容。用原账号重新登录后重试保存，再退出或切换账号。
